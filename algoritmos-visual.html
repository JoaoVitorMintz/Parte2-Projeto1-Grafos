Grafo construído pelo backend

Clique em um vértice ou em um abrigo da lista para destacar suas conexões. Role para dar zoom e arraste para mover. No mapa, passe o mouse numa aresta para ver a distância em km.

Mapa real: cada abrigo fica na coordenada verdadeira e todas as arestas retornadas pelo backend são desenhadas (abrigos sem coordenada não aparecem no mapa). Clique em um abrigo para destacar todas as conexões dele; no Dijkstra o caminho mínimo até o destino fica em azul por cima das demais arestas. Diagrama: redesenha o grafo sem usar a posição real, só pra enxergar a estrutura (por padrão com um resumo das arestas). Se a API retornar 0 arestas, a causa está no grafo construído pelo backend, não no HTML.
