# Parte 2 - Projeto 1 de Grafos

## Como rodar ⚙️

Ao compilar, os arquivos `.class` será gerado dentro de java-build:

```terminal
javac -d /tmp/java-build *.java
```

Para rodar:

```terminal
java -cp /tmp/java-build Menu
```

Para limpar a pasta gerada com o `.class` dentro?

```terminal
rm -rf /tmp/java-build
```
